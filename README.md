# Private Vault landing page

This folder is a static, public-safe landing page for GitHub Pages. It contains no Telegram bot token, database credentials, private media, or vault metadata.

To publish it from a dedicated GitHub repository, copy the contents of this folder to the repository root and enable **Settings → Pages → GitHub Actions**. The landing page links to `@PrivateMediaVaultBot`; the private dashboard and webhook remain on the server-side app.
